# MessWise Data Dictionary

Synthetic data: 183 days (2026-04-22 to 2026-10-21) x 3 meals = 549 rows, for a hostel of 600 students.
Generated by `data/generate_data.py` (seed 42). Patterns are assumptions, not measured values; replace with real mess logs when available.

| Field | Type | Description |
|---|---|---|
| date | date (YYYY-MM-DD) | Day of the meal |
| day_of_week | text | Monday ... Sunday |
| meal | text | breakfast, lunch or dinner |
| menu_item | text | Main dish served (weekly timetable plus about 12% special-menu swaps) |
| menu_popularity_score | int 1-5 | How popular the dish is with students (5 = biryani/dosa/parotta) |
| is_holiday | 0/1 | Public/festival holiday (students go home) |
| is_exam_week | 0/1 | Exam window (students skip or shift meals) |
| is_weekend | 0/1 | Saturday or Sunday |
| weather | text | normal, hot or rain |
| expected_attendance | int | Mess staff headcount estimate. Knows the weekday pattern, not holidays, menu, weather or exams |
| actual_servings | int | Students who actually came to eat (the value we forecast). On shortage days it is the true demand |
| food_prepared | int | Servings cooked under current practice (expected headcount + 12%) |
| food_wasted | int | max(food_prepared - actual_servings, 0) |
| shortage_flag | 0/1 | 1 if actual_servings > food_prepared (mess ran short) |

## Patterns built into the data
- Weekend dip; Sunday dinner drop to about 68% of normal
- Special menus (biryani, dosa, parotta) lift demand 14-19%; low-popularity dishes (upma, sambar rice) cut it
- Holidays cut demand 35-45%; exam weeks cut it 5-15%
- Rain lowers breakfast by 12%; hot weather lowers lunch by 5%
- About 3.5% random noise on top

## Cost assumption
Rs 60 per serving wasted (as specified in the brief).
